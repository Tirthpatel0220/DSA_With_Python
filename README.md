## 🎯 Core Philosophy

Writing DSA in Python often suffers from two extremes: either falling back to built-in C-optimized black boxes (`list.sort()`, `collections.deque`) without understanding how they work, or writing clumsy, un-idiomatic C++ translations into Python.

This repository is built to strike the right balance:
1. **Under-the-Hood Foundations:** Data structures are implemented from bare memory primitives where possible (e.g., custom arrays with fixed capacity, pointer-based linked lists) to understand memory layouts.
2. **Idiomatic Pythonic Implementations:** Clean use of magic methods (`__len__`, `__iter__`, `__getitem__`), standard protocols, generators for space-efficient traversals, and strict type hints via `typing`.
3. **Complexity & Benchmarking:** Every script contains explicit Big-O annotations ($O(N)$ Time & Auxiliary Space) alongside micro-benchmarks comparing custom structures with Python standard libraries.
